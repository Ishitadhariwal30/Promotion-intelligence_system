#   pip install -r requirements.txt
#   streamlit run app.py
#
# ============================================================
# WHY THESE ARE PINNED WITH == AND NOT >=
# ============================================================
#
# `>=` means "this version or anything newer". On your laptop that is
# harmless, because the packages were installed months ago and stay put.
# On Streamlit Cloud the container is built fresh, so `>=` resolves to
# whatever is newest that morning - which is not what anything was
# tested against.
#
# That is not hypothetical here. `pandas>=2.0.0` resolved to pandas 3,
# where text columns have dtype `str` instead of `object`. Any code
# checking `dtype == object` silently stops matching, encoding is
# skipped, and LightGBM fails much later with an error that points
# nowhere near the cause.
#
# Pinning means the app that gets deployed is the app that was tested.
#
# These exact versions were verified end to end by tests/smoke_test.py -
# data loads, model loads, one customer scores.
#
# To upgrade: change one pin, run tests/smoke_test.py, commit only if
# it passes. Never bump them all at once - if something breaks you will
# not know which one did it.
# ============================================================
